## 🚛 Karvon

<a href="https://github.com/Khan-ipak/karvon">
  <img src="https://raw.githubusercontent.com/Khan-ipak/karvon/main/docs/img/social-preview.png" alt="Karvon: open-source Terminal Operating System for land freight terminals" width="640">
</a>

**[Karvon](https://github.com/Khan-ipak/karvon)** is an open-source Terminal Operating System for
dry ports, border truck terminals and TIR parks. It covers the gate, yard, cross-docking,
warehouse, weighbridge and billing, with roles, an audit log and reports, in English, Russian and Uzbek.

**[▶ Live demo](https://karvon-demo.onrender.com)** (log in as `admin` / `admin`) ·
